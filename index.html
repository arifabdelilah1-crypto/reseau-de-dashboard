🚀 Déployer sur GitHub Pages
Gratuit · URL publique · Auto-update
Créer un compte GitHub (si pas encore fait)
Va sur github.com → Sign Up. Gratuit.
Créer un nouveau repository public
Clique New repository → Nom: reseau-de-dashboard → Public → Create repository
Télécharger ce fichier HTML
Clique le bouton Télécharger ci-dessous → renomme le fichier en index.html
Uploader le fichier dans GitHub
Dans ton repo → Add file → Upload files → glisse index.html → Commit changes
Activer GitHub Pages
Settings → Pages → Source: Deploy from a branch → Branch: main → Folder: / (root) → Save
Ton URL est prête en 2 minutes !
L'URL sera: https://TON-USERNAME.github.io/reseau-de-dashboard/
Pour mettre à jour: re-upload index.html dans GitHub → les données statiques se mettent à jour automatiquement.
🔄 Mettre à jour les données (workflow manuel)
Copier l'onglet Master de ton Google Sheet
Dans ton sheet → clic droit sur l'onglet Master → Copier vers → Nouveau classeur → Partage public (lecture seule)
Remplacer l'ID du sheet dans ce fichier
Dans index.html, cherche SHEET_ID et remplace par l'ID de ta copie publique. Re-upload sur GitHub.
